# ⏱️ Time Calculator (PHP 8)

A modern and visually appealing **time difference calculator** built with **PHP 8**.

This project calculates the time between two dates in:
- Years
- Months
- Days
- Hours
- Minutes
- Seconds

Originally created during a **PHP 8 course at ByteLab** and later extended with custom features and UI improvements.

---

## 🚀 Features

- 📅 Date input via form
- ⏳ Calculates exact time difference
- 🧮 Output in multiple units (years → seconds)
- 🎨 Modern UI with background images
- 📱 Responsive layout
- ⚡ Fast and lightweight (pure PHP, no framework)

---

## 🛠️ Technologies

- PHP 8
- HTML5
- CSS3
- (Optional) JavaScript for UI enhancements

🧠 How it works
User enters a date
PHP processes the input
Time difference is calculated using PHP DateTime
Results are displayed dynamically
